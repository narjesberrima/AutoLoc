# \# AutoLoc

# 

# AutoLoc est une plateforme de gestion de location de véhicules multi-agences.

# 

# \## Objectifs

# \- Gérer les véhicules disponibles à la location

# \- Gérer les clients et les réservations

# \- Gérer plusieurs agences

# \- Suivre les opérations de location

# 

# \## Acteurs

# \- Client

# \- Agent d'agence

# \- Responsable d'agence

# \- Administrateur
